System Architecture & Mod Manager

The First True Multi-Mod Loader for Crazy Taxi 1

Historically, modifying Crazy Taxi 1 on PC was practically nonexistent or restricted to breaking single-purpose ASI scripts, destructive archive overwrites, and incompatible hacks. Lyras Crazy Taxi Framework establishes the first unified Multi-Mod Loader & Manager in Crazy Taxi history, capable of discovering, chaining, and running multiple mods simultaneously in memory.

You can load as many mods as you want: simply drop new mod DLLs, custom texture packages, or gameplay scripts into the mods/ directory. The framework loads and initializes every module concurrently without conflict, complete with an in-game DirectX 9 GUI overlay to toggle and adjust settings in real time.

Real-time Direct3D 9 in-game overlay: Manage multiple mods, toggle modules, and tune engine parameters on the fly
Mod Loader Architecture: DirectInput8 Proxy Loader (dinput8.dll) with dynamic module chaining
Texture Engine Integration: Natively integrated Drag & Drop Texture Modder (v0.88) with real-time 2K HD injection
Multi-Mod Concurrency: Simultaneous live modules (Lyras Framework + Texture Mod + DC Restoration + Community Submods)
Mod Management: Modular mods/ directory — drop in or remove mods with zero friction
Runtime GUI Control: In-game DirectX 9 menu overlay with real-time parameter tuning (F7 / Shift+F1)
Zero Game Tampering: 100% untouched game archives (data_little/) — clean zero-footprint uninstall

Deployment Guide

Zero-Installer Drag & Drop Setup

The framework requires no installer executable (.exe) and makes zero modifications to original game archives. Follow the 4 steps or watch the full installation walkthrough below.

Official Guide 1080p Full HD

Video Walkthrough: Manual Installation Process

Drive Full HD ↗
STEP 01

Extract Package

Download and extract Lyras Framwork MOD.zip. The package contains dinput8.dll and the mods/ directory.

STEP 02

Locate Game Directory

Open the folder containing Crazy Taxi.exe. Fully supported paths include:

Steam: C:\Program Files (x86)\Steam\steamapps\common\Crazy Taxi\ 2014/2016 Downloads: ...\Downloads\Crazy Taxi\2014\ (or \2016\)
STEP 03

Copy Hook & Manage Mods

Drag dinput8.dll and mods/ into the root folder next to Crazy Taxi.exe. Drop any other mods or texture packs into mods/ to load and manage them concurrently.

STEP 04

Launch & Play

Run Crazy Taxi.exe. The mod loader automatically hooks in. Press Shift + F1 (or F7 / F10) at any time to open the in-game mod menu.

Universal Compatibility & Clean Uninstallation: Compatible with Steam, 2014 unofficial, and 2016 unofficial releases out of the box with zero configuration. To completely uninstall, simply delete dinput8.dll and the mods/ directory. Original game files remain 100% vanilla and untouched.
