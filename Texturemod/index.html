Technical Rules & Limits

Custom Texture Specifications & Safeguards

Official specifications extracted from the Crazy Taxi Texture Modding Guide to ensure stability and smooth 60 FPS gameplay.

Mandatory Rule

Strict Power-of-Two (POT) Rule (2ⁿ)

Direct3D 9 texture hardware requires dimensions to be powers of two:

16, 32, 64, 128, 256, 512, 1024, 2048

  • ✓ Why 1280 broke performance: 1280 is Non-Power-of-Two (NPOT). Arbitrary 10x scalings violate GPU hardware expectations and cause stalls. Always upscale by binary factors.
  • ✓ 2×: 128 → 256 • 4×: 128 → 512
  • ✓ 8×: 128 → 1024 (Recommended HD standard)
  • ✓ 16×: 128 → 2048 (Maximum safe limit)
Aspect Ratio & Asset Types

Preservation & UV Mapping

Maintain original aspect ratios to avoid distorted decals or stretched buildings:

  • ✓ Square (1:1): 128×128 → 512×512 or 1024×1024.
  • ✓ Rectangular (2:1): 256×128 → 1024×512 or 2048×1024.
  • ✓ 3D World & Vehicles (3D_OBJECT__, 3D_STAGE__): Full upscaling up to 2048×2048 via normalized UV coordinates (0.0f - 1.0f).
  • ✓ 2D HUD & Menus (2D_SPRITE__, 2D_UI__): Up to 2× or 4× scaling supported. Check screen-space alignment.
Naming Convention

Deterministic File Naming

Never rename extracted texture files. The mod uses deterministic hash and offset lookups:

{Category}__{ArchiveName}__{ChunkIndex:04d}__GBIX_{Hex}__FMT_{Format}_{Width}x{Height}__HASH_{CRC32}.png

You may save as .png, .jpg, or .jpeg. The mod dynamically picks the file with the most recent timestamp.

Hard Engine Limits & VRAM Budget

Constraint Limit Technical Consequence of Exceeding
Max Texture Dimension 2048 × 2048 Direct3D 9 texture allocation fails on resolutions ≥ 4096, triggering a fallback to native low-res textures.
Max VRAM per Texture 16 MB (2048 × 2048 32-bit ARGB) Single textures above 16 MB cause GPU memory bus stalls.
Process Memory Budget ~1.8 GB (32-bit CrazyTaxi.exe) Upscaling every texture to 2048 exhausts 32-bit address space. Recommended: 1024×1024 for cars/roads, 512×512 for secondary props.
DirectX Sampler Filter 8x Anisotropic Filtering Handled automatically by the mod for all high-res replacements.
View Built-in Automated Safeguards (Dimension Snapper, Smart Alpha, Auto-Mipmaps)
  • ✓ HD Dimension Snapper & Aspect Ratio Guardian: Automatically snaps and resamples non-power-of-two user images (e.g. 1280×1280) down to the nearest valid power-of-two (1024×1024) using high-quality bicubic filtering. Corrects distorted aspect ratios to fit the 3D model's UV layout.
  • ✓ Smart Format & Alpha Restoration Engine (MS Paint & JPG Friendly): When editors strip transparency and save 24-bit RGB, the engine automatically retrieves the original alpha channel from originals/. Pure magenta (#FF00FF / RGB 255, 0, 255) is also keyed to 100% transparent pixels.
  • ✓ Guaranteed Mipmap Pyramids & 60 FPS: Generates hardware mip chains (D3DUSAGE_AUTOGENMIPMAP) or custom CPU 2×2 box-filter downsampling pyramids down to 1×1. Distant objects sample from tiny mip levels, preventing shimmering or aliasing at rock-solid 60 FPS.
  • ✓ Smart Binary Cache (cache/): Modified textures are compiled on startup into optimized .cache binaries. Subsequent game launches load custom textures in microseconds.
